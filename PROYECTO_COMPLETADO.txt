📞 SOPORTE TÉCNICO:
═══════════════════════════════════════════════════════════════════════════════

Si la aplicación no inicia:
  1. Verifica Python: python --version
  2. Reinstala dependencias: pip install -r requirements.txt --force-reinstall
  3. Usa: streamlit run app.py --logger.level=debug

Si hay errores de módulos:
  1. Verifica la estructura de carpetas
  2. Asegúrate que estés en la carpeta correcta
  3. Ejecuta desde la raíz del proyecto

Si los reportes no se generan:
  1. Verifica permisos de carpeta output/
  2. Intenta crear la carpeta manualmente
  3. Revisa el espacio en disco
